公开页面：**https://fan930450-cpu.github.io/nazhietf/**

单页仪表盘：看嘉实纳斯达克100（159501）和纳指100同类 ETF 的溢价，并按固定规则算出今天建议定投多少钱。用浏览器打开上面的网址即可，**不需要安装，不需要登录，不需要 Grok Bot**。

## 第一次打开前：启用 GitHub Pages（只需一次）

GitHub 不会在空仓库上自动把 Pages 的发布源改成 Actions。工作流文件已经在 `main` 上，但要你在网页里点一次，线上地址才会通：

1. 打开 [Settings → Pages](https://github.com/fan930450-cpu/nazhietf/settings/pages)。
2. 在 **Build and deployment** 里，把 **Source** 选成 **GitHub Actions**。不要选 “Deploy from a branch”。
3. 打开工作流 [刷新并部署日报](https://github.com/fan930450-cpu/nazhietf/actions/workflows/refresh-pages.yml)，点 **Run workflow** → **Run workflow**。
4. 这一轮变绿之后，访问 **https://fan930450-cpu.github.io/nazhietf/** 。第一次发布通常要等一两分钟。

如果设置页里还没有 “GitHub Actions” 这一项，先确认默认分支 `main` 上已经有 `.github/workflows/refresh-pages.yml`，刷新设置页再选。选好之前，定时任务跑起来也会在部署那一步失败；选好后重新运行即可。

定时任务只在默认分支 `main` 上生效。

## 页面上有什么

- **今日建议定投金额**：基准金额默认 **3000** 元。回撤系数看距近一年最高净值的回撤，较上月净值只作参照。计算器可以改选其他纳指100 ETF，自动填入该只自己的高点回撤、单日涨跌、溢价和 P60。基准金额、本月已投和备用金在切换时保持不变；后两项记在浏览器本地。建议金额 = 基准 × 回撤系数 × 溢价系数，没有 2 倍上限。买多少主要由回撤决定，溢价只做轻度修正。
- **建议买入代码**：159501 明显贵时，改成同类里参考溢价更低的一只（例如 159513），不在标普、日经里挑。
- **溢价 P、近 60 日溢价中位数 P60、距近一年高点的回撤、较上月净值（参照）、是否卖战术仓**。有持仓时，卖出会写成人民币：大约合计市值的 6%，并且不超过本年还能卖的额度，卖完还要留下至少 75% 的本年峰值市值。
- **买卖记录本**：记日期、买/卖、账户（平安证券 / 银河证券）、纳指100或标普500、代码、金额、价格、溢价和备注。持仓快照（数量和成本）与流水分开：流水是日记，卖出和浮盈亏看持仓快照 × 现价。新买入可以勾选按金额加权更新持仓。数据在浏览器本地（`nazhietf.trades`、`nazhietf.holdings`），可导出 / 导入 JSON，**不要把导出文件提交进仓库**。第一次打开、本地还没有记录时，会写入 2026-11-02 的持仓截图和三笔笔记；清空之后不会再自动写入。广发纳指按同类表记为 159941。
- **159501 历史溢价图**（日溢价、P60、10% 与 18% 参考线）。Chart.js 放在仓库里，不依赖外部 CDN；打不开图表时会改画 SVG。
- **今日同类怎么选**：放在金额下面、计算器上面。先是纳指100短名单，再是标普500短名单。净值日落后的标成「净值未齐」，不拿它的回撤和已更新的基金比，也不让它当今日优先。顶部金额仍只按 159501 计算。
- **同类对比表**：纳指100全表，按收盘参考溢价从低到高。

金额规则（和页面脚本一致）：

- 回撤系数看距近一年最高净值的回撤：&lt;5% 为 1.0；之后按锚点分段线性，5% 为 1.67，10% 为 3.33，15% 为 6.67，20% 为 8.33，25% 为 10.0，30% 为 11.67，40% 为 13.33，再深仍是 13.33。例如 7.5% 约为 2.5，12.5% 约为 5.0。最新净值日跌幅 ≥3%，在这个系数上再 +0.5。较上月净值不进入这个系数。
- 溢价系数只轻度修正金额，买多少仍主要由回撤系数决定。相对自己的 P60 连续变化（低 5 个点为 1.15，持平为 1.00，高 5 个点为 0.85）。绝对软顶：P≥22% 不超过 0.85，P≥18% 不超过 0.90，P≥15% 不超过 0.95。比最便宜同类贵 5 个点及以上不超过 0.90。距高点回撤 ≥15% 时溢价系数不低于 0.95，≥10% 时不低于 0.90。
- 建议金额 = 基准 × 回撤系数 × 溢价系数，没有 2 倍上限。深回撤可以到基准的 13.33 倍，页面会提醒看备用金。
- 卖战术仓：净值处在近 60 日新高，并且溢价明显贵，才触发。没有持仓记录时仍只提示卖总市值的 5–8%。有持仓时，建议金额取合计市值的 6%（5–8% 的中位），再限制在「本年已卖不超过峰值市值的 20%」和「卖后剩余至少是峰值市值的 75%」里面。优先卖持有的、溢价更高的那只纳指（若触发的是标普，则卖标普）。仅供个人记录辅助，不是投资建议。
- **标普500**是另一条定投，在纳指金额下面单独一张卡片，计算器在纳指定投计算器下面。基准默认 **2000** 元。回撤不足 5% 系数为 1；从 5% 起系数为回撤百分点 ÷ 2（5%→¥5000，10%→¥10000，15%→¥15000，20%→¥20000，25%→¥25000，30%→¥30000，35%→¥35000，40%→¥40000，更深仍按这个斜率，不封顶）。中间线性。前一净值日跌幅 ≥3%，系数再 +0.5。溢价系数和纳指同一套轻度修正，但 P60 和最便宜同类只用标普短名单（513500、513650、159655）。513500 明显贵时，买入代码改到标普短名单里更合适的一只。标普卖出只按标普持仓计算。仅供个人记录辅助，非投资建议。

## 自动刷新怎么跑

工作流名称：**刷新并部署日报**（`.github/workflows/refresh-pages.yml`）。

会在三种情况下运行：

| 触发 | 时间 |
| --- | --- |
| 定时 | 周一到周五，北京时间 **10:20、11:20、12:20、13:20、14:20**（UTC `20 2-6 * * 1-5`）。这是标签页关掉之后的兜底快照。GitHub 的定时任务偶尔会晚几分钟，甚至漏掉一次。 |
| 页面打开时 | A 股交易时段（9:30–11:30、13:00–15:00）大约每 **20 秒**从腾讯财经公开行情重取现价、IOPV 和溢价，并重算溢价系数、建议金额和短名单。标签页切到后台会暂停。高点回撤、P60、单日净值涨跌仍只用上面的定时快照。下单以券商 IOPV 为准。 |
| 手动 | Actions 页面里的 **Run workflow** |
| 推送 | 有人把提交推进 `main` |

每次运行做这些事，**不读取、不需要任何 secret / token**（只用 Actions 自带的 `GITHUB_TOKEN` 提交数据和发布页面）：

1. `python3 refresh.py` 从公开接口拉数：东方财富净值、新浪或腾讯日 K、QDII Lens 上纳指100 ETF 的收盘参考溢价，以及现价。
2. 重写 `data.js`、`data/premium_159501.csv`、`data/peers_latest.csv`、`data/dashboard_payload.json`、`data/nav_159501.csv`。
3. 若数据有变化，用机器人账号把这些文件提交回 `main`。这次提交不会再次触发工作流。
4. 用官方的 `actions/upload-pages-artifact` 和 `actions/deploy-pages` 把站点发布到 GitHub Pages，线上页面随之更新。

某个数据源暂时打不开时，脚本沿用仓库里上一份成功快照，页面仍会发布，页眉会写明“注意”。

## 在自己电脑上打开

```bash
python3 refresh.py   # 可选，更新数据
```

然后直接用浏览器打开本目录的 `index.html`（`file://` 即可）。请让 `index.html`、`data.js`、`ledger.js` 和 `vendor/` 留在一起。只需要本机的 Python 3.10+ 标准库，没有第三方包。买卖记录在浏览器本地，换浏览器或清站点数据会丢，先导出 JSON。

## 数据口径

| 字段 | 口径 |
| --- | --- |
| 历史溢价 | 当日收盘价 ÷ 当日单位净值 − 1 |
| 今日展示溢价 P | 优先 QDII Lens 收盘参考溢价（价 / IOPV − 1） |
| P60 | 近 60 个交易日「净值折溢价」的中位数 |
| 距近一年高点回撤（回撤系数的输入） | 最新净值相对近 365 天内最高净值下跌的百分比，并标出高点日和净值日 |
| 前一净值日涨跌 | 最新净值相对上一个净值日。跌幅 ≥3% 时回撤系数当天 +0.5 |
| 较上月净值 | 最新净值相对约一个月前同一天。只作参照，不进回撤系数 |
| 短名单参考溢价 | QDII Lens 收盘参考溢价（价 / IOPV − 1），页面标注交易日 |
| 管理+托管费 | 产品资料概要或定期报告里的年费率，两者相加 |
| 年化跟踪误差 | 东方财富基金特色数据；没有则页面留空 |

QDII 净值经常晚 1–2 个交易日。未收盘时，脚本不用当天那根未完成的日 K 当作收盘价。盘中下单请以券商 IOPV 为准。

## 回撤系数口径

回撤系数看 **距近一年最高净值的回撤**，不再用较上月净值。较上月净值仍显示在日报和计算器里，标明「只作参照」。近 60 日净值新高只用来判断要不要卖战术仓。

不足 5% 时系数为 1.0。从 5% 起按锚点分段线性：5% 为 1.67，10% 为 3.33，15% 为 6.67，20% 为 8.33，25% 为 10.0，30% 为 11.67，40% 及更深为 13.33。中间线性，例如 7.5% 约为 2.5，12.5% 约为 5.0。金额没有 2 倍上限。最新一个净值日如果比前一日跌了 3% 或更多，当天的回撤系数再加 0.5。净值日落后于同类的基金会标出来，不拿错开的窗口互相比较回撤。
