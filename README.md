## 第一次打开前：启用 GitHub Pages（只需一次）

GitHub 不会在空仓库上自动把 Pages 的发布源改成 Actions。工作流文件已经在 `main` 上，但要你在网页里点一次，线上地址才会通：

1. 打开 [Settings → Pages](https://github.com/fan930450-cpu/nazhietf/settings/pages)。
2. 在 **Build and deployment** 里，把 **Source** 选成 **GitHub Actions**。不要选 “Deploy from a branch”。
3. 打开工作流 [刷新并部署日报](https://github.com/fan930450-cpu/nazhietf/actions/workflows/refresh-pages.yml)，点 **Run workflow** → **Run workflow**。
4. 这一轮变绿之后，访问 **https://fan930450-cpu.github.io/nazhietf/** 。第一次发布通常要等一两分钟。

如果设置页里还没有 “GitHub Actions” 这一项，先确认默认分支 `main` 上已经有 `.github/workflows/refresh-pages.yml`，刷新设置页再选。选好之前，定时任务跑起来也会在部署那一步失败；选好后重新运行即可。

定时任务只在默认分支 `main` 上生效。

## 页面上有什么

- **今日建议定投金额**：基准金额默认 **3000** 元。只要腾讯行情时间戳是今天，回撤就用今日 IOPV 相对近一年最高公布净值，午休和收盘后也一样，不必等明天的净值。行情不是今天，或没取到 IOPV 时，才退回已公布净值并标明滞后。较上月净值只作参照。计算器可以改选其他纳指100 ETF，自动填入该只自己的回撤、单日涨跌、溢价和 P60。基准金额、本月已投和备用金在切换时保持不变；后两项记在浏览器本地。建议金额 = 基准 × 回撤系数 × 溢价系数，没有 2 倍上限。买多少主要由回撤决定，溢价只做轻度修正。仅供个人记录辅助，非投资建议。
- **建议买入代码**：159501 明显贵时，改成同类里参考溢价更低的一只（例如 159513），不在标普、日经里挑。
- **溢价 P、近 60 日溢价中位数 P60、距近一年高点的回撤、较上月净值（参照）、是否卖战术仓**。有持仓时，卖出会写成人民币。纳指和标普分开：大约该边市值的 6%，不超过该边本年还能卖的额度，卖完还要留下至少 75% 的该边峰值市值。
- **买卖记录本**：记日期、买/卖、券商（平安证券 / 银河证券 / 招商证券，或手填其他）、纳指100或标普500、代码、金额、价格、溢价和备注。持仓快照按券商和代码分开记数量、成本；卖出额度仍按纳指、标普各自合计，不按券商拆开，汇总下面可以再按券商看市值。流水是日记，卖出和浮盈亏看持仓快照 × 现价。新买入可以勾选按金额加权更新持仓。持仓与买卖记录只存在本机浏览器 localStorage（`nazhietf.trades`、`nazhietf.holdings`）；别人打开同一网址看不到你的数据，也改不了你的数据，每人各自一份本地数据。没有服务器上的共享账本，也不会把账本同步到云端。第一次打开是空的持仓和空的流水。要换到另一台设备，点「导出 JSON」下载备份，再到那台设备的同一页面点「导入 JSON」恢复；导入只写进这一台浏览器，不会上传。导出文件带 `broker` 字段，**不要把导出文件提交进仓库**。以前自动写入、并且仍标着内置标记的示例行，会在打开页面时从这台浏览器拿掉；你自己保存过的行，以及你导入的备份，会留下。清空之后仍是空的。广发纳指按同类表记为 159941。
- **159501 历史溢价图**（日溢价、P60、10% 与 18% 参考线）。Chart.js 放在仓库里，不依赖外部 CDN；打不开图表时会改画 SVG。
- **今日同类怎么选**：放在金额下面、计算器上面。先是纳指100短名单，再是标普500短名单。今天买哪只只看同一日的参考溢价和成交；净值日相差一个公布日是 QDII 常态，不因此取消更低溢价的今日优先。落后超过一个公布日的标成「净值未齐」，提示不要拿它的回撤和已更新的基金比。159501 明显贵，或比短名单里更便宜的一只贵出约 5 个点时，建议买入代码改到更便宜的短名单，而不是仍写 159501。顶部金额仍只按 159501 计算。
- **同类对比表**：纳指100和标普500分两张表，各自按参考溢价从低到高。标普至少包括短名单里的 513500、513650、159655，以及 QDII Lens 上的其他标普500 ETF。基金规模用 QDII Lens 或天天基金规模变动表里的期末净资产，单位是亿、保留一位小数，并标明截至日期；取不到就留空，不编数字。盘中现价、IOPV 和参考溢价仍按公开行情更新。
- **页底美股图**：QQQ 回撤、SPY 回撤和 VIX。回撤 = 收盘价 ÷ 近 365 天滚动最高收盘价 − 1。近一个月、近半年、近一年只改显示窗口，同一天的回撤不变。没有 `nazhietf.usRange` 或值无效时，窗口默认是近一个月。每台浏览器用 `nazhietf.usRangeDefaultMonthV1` 在这次改默认后强制回到近一个月一次（包括之前误存的一年）；之后再点的区间会记在 `nazhietf.usRange`，刷新不再改回去。左轴是回撤，右轴是 VIX。定时刷新从 Yahoo chart v8 取日线，VIX 失败时改用 CBOE。取不到就不编数，页上会写明。仅供个人记录辅助，非投资建议。

金额规则（和页面脚本一致）：

- 回撤系数看距近一年最高公布净值的回撤。交易时段用今日盘中 IOPV 代替滞后的公布净值：回撤 = 高点净值 − 今日 IOPV，再除以高点净值。没有今日 IOPV 时用已公布净值。&lt;5% 为 1.0；之后按锚点分段线性，5% 为 1.67，10% 为 3.33，15% 为 6.67，20% 为 8.33，25% 为 10.0，30% 为 11.67，40% 为 13.33，再深仍是 13.33。例如 7.5% 约为 2.5，12.5% 约为 5.0。最新净值日跌幅 ≥3%，在这个系数上再 +0.5。较上月净值不进入这个系数。标普用自己的阶梯，但回撤同样优先今日 IOPV。
- 溢价系数只轻度修正金额，买多少仍主要由回撤系数决定。相对自己的 P60 连续变化（低 5 个点为 1.15，持平为 1.00，高 5 个点为 0.85）。绝对软顶：P≥22% 不超过 0.85，P≥18% 不超过 0.90，P≥15% 不超过 0.95。比最便宜同类贵 5 个点及以上不超过 0.90。距高点回撤 ≥15% 时溢价系数不低于 0.95，≥10% 时不低于 0.90。
- 建议金额 = 基准 × 回撤系数 × 溢价系数，没有 2 倍上限。深回撤可以到基准的 13.33 倍，页面会提醒看备用金。
- 卖战术仓：某一边净值处在近 60 日新高，并且溢价明显贵，才触发那一边。没有该边持仓时仍只提示卖该边市值的 5–8%。有持仓时，建议金额取该边市值的 6%（5–8% 的中位），再限制在「本年已卖不超过该边峰值市值的 20%」和「卖后剩余至少是该边峰值市值的 75%」。纳指底仓和标普底仓不合并。仅供个人记录辅助，不是投资建议。
- **标普500**是另一条定投，在纳指金额下面单独一张卡片，计算器在纳指定投计算器下面。基准默认 **2000** 元。回撤不足 5% 系数为 1；从 5% 起系数为回撤百分点 ÷ 2（5%→¥5000，10%→¥10000，15%→¥15000，20%→¥20000，25%→¥25000，30%→¥30000，35%→¥35000，40%→¥40000，更深仍按这个斜率，不封顶）。中间线性。前一净值日跌幅 ≥3%，系数再 +0.5。溢价系数和纳指同一套轻度修正，但 P60 和最便宜同类只用标普短名单（513500、513650、159655）。513500 明显贵时，买入代码改到标普短名单里更合适的一只。标普卖出只按标普持仓计算。仅供个人记录辅助，非投资建议。

## 自动刷新怎么跑

工作流名称：**刷新并部署日报**（`.github/workflows/refresh-pages.yml`）。

会在三种情况下运行：

| 触发 | 时间 |
| --- | --- |
| 定时 | 周一到周五，北京时间 **9:50**（UTC `50 1 * * 1-5`），以及 **10:20、11:20、12:20、13:20、14:20**（UTC `20 2-6 * * 1-5`）。9:50 是开盘后的第一份快照，后面每小时再补一笔。GitHub 的定时任务偶尔会晚几分钟，甚至漏掉一次。交易时段的快照会写上当天的现价、IOPV 和溢价，页眉的行情日跟着这一天；净值日仍可能晚 1–2 天。 |
| 页面打开时 | A 股交易时段（9:30–11:30、13:00–15:00）大约每 **20 秒**从腾讯财经公开行情重取现价、IOPV 和溢价，并重算溢价系数、建议金额和短名单。拉不到时会改用脚本方式再试一次，失败原因写在页眉「行情更新时间」旁边，不再停在「等待公开行情」。也可以点 **刷新行情**。标签页切到后台会暂停。高点回撤、P60、单日净值涨跌仍只用上面的定时快照。净值日晚于行情日是 QDII 披露时滞。下单以券商 IOPV 为准。 |
| 手动 | Actions 页面里的 **Run workflow** |
| 推送 | 有人把提交推进 `main` |

每次运行做这些事，**不读取、不需要任何 secret / token**（只用 Actions 自带的 `GITHUB_TOKEN` 提交数据和发布页面）：

1. `python3 refresh.py` 从公开接口拉数：东方财富净值、新浪或腾讯日 K、QDII Lens 上纳指100 ETF 的收盘参考溢价，以及现价。
2. 重写 `data.js`、`data/premium_159501.csv`、`data/peers_latest.csv`、`data/dashboard_payload.json`、`data/nav_159501.csv`。
3. 若数据有变化，用机器人账号把这些文件提交回 `main`。这次提交不会再次触发工作流。
4. 用官方的 `actions/upload-pages-artifact` 和 `actions/deploy-pages` 把站点发布到 GitHub Pages，线上页面随之更新。

某个数据源暂时打不开时，脚本沿用仓库里上一份成功快照，页面仍会发布，页眉会写明“注意”。

## 在自己电脑上打开

```bash
python3 refresh.py   # 可选，更新数据
```

然后直接用浏览器打开本目录的 `index.html`（`file://` 即可）。请让 `index.html`、`data.js`、`ledger.js` 和 `vendor/` 留在一起。只需要本机的 Python 3.10+ 标准库，没有第三方包。买卖记录在浏览器本地，换浏览器或清站点数据会丢，先导出 JSON。

## 数据口径

| 字段 | 口径 |
| --- | --- |
| 历史溢价 | 当日收盘价 ÷ 当日单位净值 − 1 |
| 今日展示溢价 P | 优先 QDII Lens 收盘参考溢价（价 / IOPV − 1） |
| P60 | 近 60 个交易日「净值折溢价」的中位数 |
| 距近一年高点回撤（回撤系数的输入） | 行情时间戳是今天就用今日盘中 IOPV 相对近 365 天内最高公布净值，午休和收盘后也算。同时显示已公布净值回撤。行情不是今天或没有 IOPV 时才用已公布净值，并标明滞后 |
| 前一净值日涨跌 | 最新净值相对上一个净值日。跌幅 ≥3% 时回撤系数当天 +0.5 |
| 较上月净值 | 最新净值相对约一个月前同一天。只作参照，不进回撤系数 |
| 短名单参考溢价 | QDII Lens 收盘参考溢价（价 / IOPV − 1），页面标注交易日 |
| QQQ / SPY 回撤 | 美股收盘价相对近 365 天滚动最高收盘价。切换图上的区间不改这个高点 |
| VIX | 恐慌指数收盘，图的右轴。优先 Yahoo `^VIX`，否则 CBOE 日线 |
| 管理+托管费 | 产品资料概要或定期报告里的年费率，两者相加 |
| 年化跟踪误差 | 东方财富基金特色数据；没有则页面留空 |

QDII 净值经常晚 1–2 个交易日。未收盘时，脚本不用当天那根未完成的日 K 当作收盘价。盘中下单请以券商 IOPV 为准。

## 回撤系数口径

回撤系数看 **距近一年最高公布净值的回撤**。行情时间戳是今天就用今日盘中 IOPV，午休和下午收盘后到当天结束也用，这样 10:30 左右以及午间都能按今天的估计净值决定买多少。已公布净值回撤仍显示在旁边。行情不是今天或没有 IOPV 时才退回已公布净值，并标明滞后。较上月净值仍只作参照。近 60 日净值新高只用来判断要不要卖战术仓。标普计算器同样优先今日 IOPV，阶梯仍是标普自己的。仅供个人记录辅助，非投资建议。

不足 5% 时系数为 1.0。从 5% 起按锚点分段线性：5% 为 1.67，10% 为 3.33，15% 为 6.67，20% 为 8.33，25% 为 10.0，30% 为 11.67，40% 及更深为 13.33。中间线性，例如 7.5% 约为 2.5，12.5% 约为 5.0。金额没有 2 倍上限。最新一个净值日如果比前一日跌了 3% 或更多，当天的回撤系数再加 0.5。净值日比同组最新公布日落后超过一个工作日的基金会标出来，不拿错开的窗口互相比较回撤。只差一个公布日不标，也不影响今日优先。
